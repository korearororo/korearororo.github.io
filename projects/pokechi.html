Pokechi

타이핑에 반응하고, 다시 열어도 기록이 남는 Windows 앱

VS Code용 Pokechi의 아이디어와 자산을 바탕으로 편집기 밖에서 실행되는 앱을 만들었습니다. 타이핑에 따라 캐릭터가 자라고, 앱을 다시 열거나 계정을 바꿔도 진행 기록을 구분해 이어갈 수 있게 했습니다.

문제

같은 계정의 여러 클라이언트가 동시에 저장하면 늦은 요청이 다른 기록을 덮어쓸 수 있습니다. 통신이 끊긴 동안 쌓인 진행도 다시 연결했을 때 유지돼야 했습니다.

해결 방향

로컬 대기 기록을 유지하고, 서버의 예상 버전을 함께 보내 저장하도록 구현했습니다. 충돌 시 최신 스냅샷과 기록을 합친 뒤 재시도합니다. 토큰과 진행 기록은 Windows 사용자·계정·모드별로 분리해 보관합니다.

실제 Windows 화면

키 입력, 부화, 재실행을 영상으로 확인할 수 있습니다

실제 Windows 앱에서 키를 입력하면 캐릭터가 부화해 도감에 등록됩니다. 앱을 닫고 다시 열어도 기록이 남는 과정을 녹화했습니다.

시연 조건

시연 저장은 XP 494/500에서 초기화했습니다. 녹화에는 누적 497 → 498 → 499 → 500과 부화 이후의 상태가 담겨 있습니다. 부화 기준과 성장 규칙은 원본 코드 그대로이며, 개인 저장 파일은 사용하지 않았습니다.

로그인·서버 통신을 포함하지 않는 로컬 기능 시연입니다. 6세대 메뉴가 보이는 로컬 검수 빌드를 사용했으며, 모든 세대의 화면 검수가 끝났다는 뜻은 아닙니다. 대기 구간을 잘라 세 장면을 연결했습니다.

영상에서 확인한 내용과 실행 자료
  • 입력 a, b, c와 앱 누적 횟수가 함께 증가하고 500에서 이상해씨가 부화합니다.
  • 도감에 이상해씨 1종이 등록됩니다.
  • 앱을 닫고 동일한 격리 파일을 불러오면 누적 500·성장 1단계·발견 1종을 유지합니다.

제가 만든 기능

독립 앱부터 저장·동기화까지

01

편집기 밖에서 동작하는 앱

전역 키보드 이벤트에서 타이핑 횟수를 성장·부화·진화에 연결했습니다. 입력한 문자·키 이름·입력 대상 앱은 저장하거나 전송하지 않습니다. 트레이, 자동 리롤, 도감과 한국어 표시, 설치 프로그램을 구성했습니다.

02

업데이트와 계정별 저장

기존 저장 형식의 백업과 변환으로 진행을 이어가도록 했습니다. Google 계정 로그인과 Supabase 동기화를 추가하고, 일반 모드와 테스트 모드의 기록을 분리했습니다.

03

충돌을 처리하는 동기화

서버는 계정과 모드별 예상 버전을 원자적으로 비교합니다. 버전이 다르면 최신 스냅샷을 반환하고, 클라이언트는 병합 후 다시 요청합니다. 전송 중 새로 생긴 UI 변경은 다음 저장 대상으로 유지합니다.

저장 방식

여러 기기가 같은 기록을 저장할 때

동기화 흐름

로컬 진행·대기 기록 → 예상 버전으로 저장 요청 → 서버의 원자적 비교 → 충돌 시 최신 기록 병합 → 재시도

덮어쓰기를 막는 조건

서버에서 예상 버전과 현재 버전을 원자적으로 비교합니다. 요청 사이에 다른 저장이 반영됐다면 최신 스냅샷을 반환하고 클라이언트가 병합합니다.

병합 규칙과 한계

발견·이로치 기록은 합집합으로, 같은 경로·모습·색의 경험치는 최대값으로 유지합니다. 중복 합산은 피하지만 두 기기에서 따로 쌓은 경험치를 모두 더하는 방식은 아닙니다.

통신과 화면 상태

Realtime 연결 외에 폴링을 보완 경로로 두고 오프라인 대기 기록을 유지합니다. 전송 중 생긴 새 UI 변경은 다음 저장 대상으로 남깁니다.

확인한 범위

영상으로 보이는 기능과 동기화 검증을 구분했습니다

실제 서버 통신

같은 Windows PC의 독립 클라이언트에서 로그인·HTTP/WSS 전달·오프라인 복원 확인

계정 분리

계정과 일반·테스트 모드의 저장 격리 확인

로그인 저장

Windows 사용자별 암호화로 갱신 토큰 보관

구현 범위와 남은 확인 사항

서로 다른 물리 PC의 설치·사용 검증은 남아 있습니다. 두 기기의 경험치는 합산하지 않고 최대값으로 유지합니다. 6세대 확장은 로컬 빌드에서 검수 중입니다. 원본 MIT 자산과 별도 출처의 스프라이트를 활용했으며 제 기여는 독립 앱과 기능 확장·저장·동기화 구현입니다.
