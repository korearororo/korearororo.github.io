# 포트폴리오 기본본 구성과 공개 기준

## 현재 기본본

웹 첫 화면은 OpenMath → Pokechi → 유동산 순서다. 첫 두 프로젝트에서는 공개 검색 비교와 실제 Windows 화면을 보여준다. 유동산 사례는 공시 기반 AI 보고서의 근거 검증과 부동산 조사실의 거래 조회·비교표 작성을 두 작업으로 구분해 소개한다. 상세 페이지는 프로젝트 목적 → 사용자 흐름 → 본인 판단과 기여 → 확인한 범위 순서다.

별도 PDF 기본본은 같은 세 사례를 네 쪽으로 편집한다. 웹 본문을 그대로 인쇄하지 않고, 검색 전후·실행 화면·유동산의 두 업무 흐름을 각 사례의 설명 옆에 둔다. PDF에서 영상이나 상세 검증이 필요한 부분은 공개 웹 사례로 연결한다. 현재 공개 링크는 `assets/portfolio/han-jinwoo-portfolio-v2-20261019.pdf`이며 v1은 이전 버전으로 보존한다.

## 사실과 공개 범위

- 유동산: 기존 회사 시스템 전체와 본인이 맡은 보고서 검증·교정 흐름 및 부동산 조사 도구의 조회·환산·비교표·출력 작업을 구분한다. 실거래가와 현재 평균 호가, 조사 시점과 면적 기준을 혼동하지 않는다. 저장 오류 복구는 내부 근거에 남기되 공개 사례의 대표 성과로 앞세우지 않는다. 내부 원문·고객 정보·실제 조사 값·비공개 코드는 게시하지 않는다.
- OpenMath: 팀 코드에 병합된 검색·정답 검증·선택 화면의 본인 기여와 전체 미병합 연계 브랜치 작업을 구분한다. 공개 예시 7문항·질의 3개는 조건 필터의 재현 자료이며 전체 검색 적합성 평가가 아니다.
- Pokechi: 원본 VS Code 확장의 아이디어·MIT 자산과 개인의 독립 Windows 앱·저장·동기화 확장을 구분한다. 실제 44초 영상은 입력·부화·도감·로컬 복원만 보여준다. 같은 PC의 독립 클라이언트에서 확인한 서버 통신과 다른 물리 PC 미검증을 분리한다. 카드·스프라이트의 예시 진행값을 실제 사용자 결과로 표현하지 않는다.

## 공개용 이력서와 재사용

`assets/resume/han-jinwoo-resume-public-v3-20261019.pdf`는 승인된 v3 이력서에서 전화·이메일과 mailto 링크를 제거한 공개 사본이다. 비공개 제출 원본, 증서와 회사 자료는 이 저장소에 넣지 않는다.

다음 지원에서는 공고의 요구 역량을 먼저 정리한 뒤 사례 순서와 첫 소개 문장만 조정한다. 백엔드·상태 관리에는 Pokechi의 버전 비교와 유동산 조사 도구의 조회·출력 흐름을, AI 응용에는 OpenMath 검색과 유동산 보고서의 근거 검증을 우선 보여줄 수 있다. 확인한 새 성과만 기본본에 추가하고, 제출 당시 사용한 파일과 웹 커밋은 별도 기록으로 보존한다. 웹 링크는 제출 후에도 최신 배포본을 보여주므로 특정 시점의 내용 보존이 필요하면 PDF나 커밋을 함께 남긴다.
