## 로컬 미리보기와 복구

저장소 루트에서 `python -m http.server 4187 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:4187/`을 연다.

시안만 폐기하려면 브랜치를 나가 `main`으로 전환하면 된다. 배포 후 되돌릴 때는 기준 커밋과 시안 커밋을 비교해 해당 변경을 되돌린 뒤 `main`을 다시 배포한다. 기준 커밋 자체는 위 SHA로 계속 조회할 수 있다.
