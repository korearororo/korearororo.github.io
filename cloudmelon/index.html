WINDOWS · NINTENDO DS

게임을 켜고,이어서 플레이하세요.

CloudMelon은 melonDS 기반의 Windows 에뮬레이터입니다. 가지고 있는 게임 파일을 실행하고, Google Drive에 세이브를 동기화할 수 있습니다.

Windows용 · Google 로그인 선택 가능
CLOUDMELON

게임 실행

PC에 준비한 게임 파일을 선택해 플레이합니다. 게임 파일은 앱에 포함되어 있지 않습니다.

세이브 동기화

Google 계정으로 로그인하면 선택한 게임의 세이브를 Drive의 앱 전용 공간에 저장합니다. 다른 PC에서도 같은 계정과 게임 파일로 이어서 플레이할 수 있습니다.

계정과 개인정보

동기화를 사용할 때 계정 이메일과 앱 전용 Drive 저장 공간에 대한 접근을 요청합니다. 로그인 없이도 오프라인으로 실행할 수 있습니다.
